# Snake Protéiné

Un jeu de Snake où le serpent mange des **shakers de protéines** au lieu de pommes, et devient de plus en plus musclé.

## Jouer

Ouvre le fichier `index.html` dans ton navigateur (double-clic dessus après l'avoir téléchargé).

- **Flèches** ou **Z Q S D** pour diriger le serpent
- **Espace** pour lancer ou relancer une partie
- Les bords se traversent : on réapparaît de l'autre côté
- On perd si le serpent se mord la queue

## Les paliers

| Palier | À partir de | Points par shaker |
|---|---|---|
| Crevette | 0 shaker | +1 |
| Débutant motivé | 5 shakers | +2 |
| Sec | 12 shakers | +3 |
| Massif | 20 shakers | +5 |
| Bête de salle | 30 shakers | +8 |
| Monstre de l'Olympia | 45 shakers | +12 |

À chaque palier, le serpent grossit, prend du muscle, puis gagne des abdos, un bandeau, des veines et enfin une aura dorée.
