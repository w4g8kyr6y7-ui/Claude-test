# Cours de marketing – L2 Éco-Gestion

- `Cours_Marketing.docx` : le cours rédigé (sommaire cliquable, encadrés « À retenir », glossaire).
- `content.js` : tout le texte du cours (c'est ici qu'on ajoute les prochains cours).
- `build.sh` : régénère le .docx (`./build.sh`), en recalculant les numéros de page du sommaire.
- `images/` : illustrations extraites des diapositives.
